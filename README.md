# AHA Collectors Challenge
Interactive website proposal curated by Abdou “Caliph” Doumbouya for December AHA, Thursday December 10, 2026.

## Run and deploy
Dependency-free static HTML, CSS, and JavaScript. Serve this directory with any static web server. Vercel project: ahadeck, production branch: main. No package installation or build required.

## Scope
12 presentation chapters, responsive navigation, sample card flip, accessible research tabs, linked sources, and print styles. This is a proposal, not a production QR reward/redemption application.

50 cards, one per person for the entire event, free distribution across five proposed downtown collection stops. Waterfront Card Shop is the separate final destination. No Problemo, ShopU7, Calico, and Play Arcade are proposed; the fifth stop is TBD.

## Sponsorship & budget ownership
A $1,500 sponsorship opportunity coordinated with AHA. Sponsors may support the full pilot or individual costs. AHA retains budget ownership, allocation and spending oversight.

## Research
Sources, dates, populations and data limits appear in the final chapter. SBoogz metrics are organizer-supplied pending analytics verification. Partner confirmations, event hours/capacity, reward mix, grand prize, and live QR redemption setup remain event planning items.

## Controls
Scroll freely; use previous/next controls or left/right arrow keys outside interactive controls. Chapter menu links are shareable. Research tabs support arrows, Home and End. Print button opens the browser print dialog, including all research panels and sources.
